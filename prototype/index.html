Prototipe Sistem Pengelolaan Lapangan Badminton

Prototipe antarmuka — 10 halaman inti

Semua halaman di bawah ini adalah prototipe HTML statis (tanpa backend) dengan data contoh GOR Smash Arena. Buka file-nya langsung di browser untuk melihat alur kerja tiap modul. Sistem dirancang berjalan pada hosting Hostinger (tanpa server lokal) dengan kanal booking telepon, WhatsApp, dan kunjungan langsung — tanpa halaman pemesanan publik.
